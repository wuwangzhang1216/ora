# Ora icon design preview

**Rejected study.** The owner rejected this first direction. See
[`research.md`](research.md) for the official reference study and revised brief.
These previews are not the selected Ora icon.

This is an unshipped design study. It does not modify the production icon, the
submitted 0.10.1 (15) binary, installed apps, or public website assets.

The mark uses a single O-shaped conversation aperture with two caption lines.
`ora-mark.svg` is the editable, monochrome master. The light and dark previews
show the same geometry, with transparent outer padding suitable for a Mac icon.

Render the native comparison and 1024 px previews:

```sh
swift design/icon-refresh/render.swift
```

Review full size and 64/32/16 px renderings before choosing a final direction.
Any App Store icon change requires a new signed build and a separate decision
about the currently submitted version; these files do not alter that submission.
